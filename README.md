# Chore Raid

> Your home is a dungeon. Each chore is a boss made of the actual mess.
> You damage it by doing the real work, one item at a time.

Count the pile, snap a before photo, then tap once for every item you finish.
The boss dies exactly when the chore is done.

Built for the Hackyard build week (theme: Gamification), Oct 5–9, 2026.

**Play it:** https://choreraid.netlify.app (best on a phone)

**Status:** in development. See [PLAN.md](PLAN.md) for the build plan.

## Run it locally

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # raid logic tests
npm run build   # production build in dist/
```
